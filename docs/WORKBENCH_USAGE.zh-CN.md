# 工作台操作：登录、模型和自己的参数

[返回首页](../README.md) · [安装步骤](GET_STARTED.zh-CN.md)

## 需要登录吗？

**当前本地工作台不需要账号、密码或注册。** 在安装目录执行 `./omindos workbench`，然后用浏览器打开 `http://127.0.0.1:8085/`。启动终端须保持运行；preview.7 默认将配置保存在 `~/.local/share/omindos-navigation/data`；旧目录迁移见[安装步骤](GET_STARTED.zh-CN.md)。

这是本机工作台，登录 OA / 官网 / 学习平台的账号不会用于这里。当前没有云端用户账号登录或自动云同步功能。

## 界面怎么分？

![Ubuntu 完整安装包实际工作台](https://github.com/maganrobotics-boop/OmindOS-Navigation-Release/releases/download/v0.2.0-preview.7/workbench.png)

图为 preview.7 Ubuntu 完整安装包的实际界面，默认加载 MEVIUS2 完整外观参考模型（13 个网格、12 个关节）。机器人外观与关节列表以导入的 URDF 为准，参数可按客户硬件设置。

| 区域 | 用途 |
| --- | --- |
| 左侧：模型和参数 | 导入 URDF / JSON；选择关节或连杆；编辑结构与电机参数 |
| 中间：三维视图 | 旋转、缩放、选择部件；观察当前关节姿态 |
| 右侧：预览和版本 | 点动、运动学试运行、软件停止；保存 / 读取版本、导出配置 |

## 1. 导入自己的模型

点击左侧 **“导入 URDF / 完整配置”**，选择 `.urdf` / `.xml` 或工作台导出的 `.json`。URDF 描述连杆、关节、转轴、连接位置和限位；完整 JSON 还可包含电机参数。两种文件上限均为 2 MiB。

导入 URDF 后，电机参数仍需按实际硬件填写。建议修改机器人编号，区分自己的机器人与参考模型。

## 2. 编辑关节和电机

选择“关节”页，再选择对应部件。

| 参数 | 填写依据与单位 |
| --- | --- |
| 相对父连杆偏移、连接距离 | 按装配尺寸填写，单位 m |
| 关节转轴、连接坐标旋转 | 转轴为 XYZ 向量；旋转 R/P/Y 为 rad |
| 关节上下限 | 实际机械限位，单位 rad |
| 电机型号、减速比 | 实际设备和传动配置 |
| 方向 | `+1` 或 `−1`，由实际安装方向确认 |
| 关节侧零点 | 实际标定偏移，单位 rad |
| 输出侧力矩、速度上限 | N·m、rad/s；按设备限制填写 |

目标关节角滑块用于姿态预览；它与零点、减速比等硬件配置字段作用不同。

## 3. 编辑连杆

切换“连杆”页，填写质量、质心和惯性张量；按支持的几何类型调整外形尺寸。

- 修改**外形尺寸**改变显示几何；关节间的**连接距离**在关节页调整。
- 修改尺寸或质量后，惯量需要重新计算并填写；系统不会自动猜测质量分布。
- 使用厂家 URDF / 参数或实测数据；参考模型不是客户机器人标定结果。

## 4. 写入、保存和备份

| 按钮 | 结果 |
| --- | --- |
| 将以上参数写入程序 | 将当前编辑配置设为工作台启动时加载的配置 |
| 保存新版本 | 校验参数、保存不可变配置版本并获得配置编号，旧版本保留 |
| 读取配置 | 用完整配置编号载入已保存版本 |
| 导出完整配置 | 下载 JSON，便于备份、迁移或 API 调用 |

建议按“编辑 → 写入当前配置 → 保存新版本 → 导出备份”操作。出现无效字段时先修正输入；读入旧版本后，如要把它设为重启默认配置，再执行写入。

这些操作作用于软件配置，**不会写入真实电机，也不会使能机器人**。需要 ROS 2 联动时另行启动服务；客户实机控制尚未验收。

## 5. 使用自己的程序

不想手动操作界面时，可调用[本地 API](API_GUIDE.zh-CN.md)提交和读取相同的配置。保存版本成功不等于参数已应用到真实硬件。
