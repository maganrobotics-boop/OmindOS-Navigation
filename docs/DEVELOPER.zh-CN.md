# 专业指南：导航、Jetson 和控制板

[返回首页](../README.md)

**普通用户先下载首页的一个 Ubuntu 完整安装包即可。** 下面用于特定开发与部署场景；不用把所有版本全部下载。

| 开发目标 | 对应指南 | 与首页安装包的关系 |
| --- | --- | --- |
| 用自己的代码配置机器人 | [API 使用指南](API_GUIDE.zh-CN.md) | 同一安装包的本地 API，无需另下算法包 |
| 差速、全向或四足机身速度的导航接口预览 | [统一导航](NAVIGATION.zh-CN.md) | 早期独立导航环境；首页完整四足包不包含该 Docker 镜像 |
| 四足参考模型的动力学与 ROS 接口 | [四足仿真](QUADRUPED_SIMULATION.zh-CN.md) | 已包含在首页完整包，无需重复下载 |
| Jetson 等 ARM64 主机 | [ARM64 部署](JETSON.zh-CN.md) | 不同 CPU 架构；Jetson 实机安装待验收 |
| DM-MC02 板卡通信台架 | [固件与上板条件](DM_MC02_BENCH_PREVIEW_1.zh-CN.md) | 独立 STM32 固件；三路 CAN 只读，禁使能 |

软件配置和仿真结果不能替代真实机器人验收。客户硬件型号、URDF、标定参数和驱动接入分别按实际设备确认。
